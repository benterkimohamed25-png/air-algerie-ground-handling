Air Algérie Ground Handling — version initiale

Fonctions :
- Ajout manuel des vols
- Catégories : intérieure, internationale, cargo
- Heures d'arrivée et de départ
- Recherche, modification et suppression
- Sauvegarde locale sur le téléphone

IMPORTANT :
Ce fichier ZIP contient le code source Flutter, pas encore un APK compilé.
Pour générer le fichier APK sans installer Flutter sur votre téléphone :
1. Sur GitHub, créez un nouveau dépôt (repository).
2. Téléversez tous les fichiers de ce ZIP en gardant la structure des dossiers.
3. Ouvrez l'onglet Actions du dépôt.
4. Lancez le workflow "Build Android APK" avec "Run workflow", ou attendez la fin du build après l'envoi du code.
5. Ouvrez l'exécution terminée et téléchargez l'artifact nommé "air-algerie-ground-handling-apk".
6. Décompressez l'artifact, puis ouvrez app-release.apk sur votre téléphone Android pour l'installer.

Il faudra autoriser l'installation depuis cette source si Android le demande.
Cette version n'utilise pas de données officielles de vols et ne programme pas encore de notifications.
